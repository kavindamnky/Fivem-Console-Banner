## 🧾 Overview

`Fivem-Console-Banner` is a lightweight and customizable UI enhancement designed to be displayed when your FiveM server boots up. It offers an aesthetic and modern feel with animated weather, server branding, and status info – perfect for personal or community servers that want to stand out.

---

## 🚀 Features

> Eye-catching features that make your FiveM console feel next-gen:

- 🎨 **Custom UI Design:** Fully responsive and clean layout with animated visuals.
- 🌦️ **Dynamic Weather Display:** Show current weather or animated placeholders.
- 💬 **Server Welcome Message:** Introduce your server with flair.
- ⚙️ **Easy Configuration:** Simple HTML/CSS/JS structure for quick modifications.
- 📊 **Performance Friendly:** Lightweight design ensures zero impact on server performance.

---

## 📖 Usage

> Quick setup in just a few steps:

1. Clone or download this repository.
2. Open `home.html` in Visual Studio Code or any preferred code editor.
3. Customize text, colors, or weather animations as needed.
4. Launch it in a browser or integrate it with your server loading screen setup.
